## 立即执行的熟人验证

W01：现公司已经试用的同事。目标是获得一个具体任务及验收意见，不是要求他成为付费用户。

可发送：

> 上次你说工具链配置麻烦、波形不清楚，这些我记下了。这次我想挑一个你最近实际做过的小任务，由我来操作，你帮我判断结果有没有用。能否找 15 分钟看一下你原来怎么做、哪一步最费时间？如果你用现有工具已经做得很顺，我也想弄清楚。我们先用方便演示的工程。

## 联系文案

### 熟人介绍

我在推进 Yoma，一个能结合真实板卡进行调试的嵌入式 agent 项目。现在想联系需要反复烧录、看日志、检查外设通信的研发负责人，验证能否把一小段人工复测做成可重复运行的流程。你能介绍一位方便聊 20 分钟的人吗？先看实际任务，匹配后再谈一个小范围付费试点。

### 方案公司 / 设备厂

你好，我是 Ben，在做 Yoma 嵌入式 agent 项目。看到贵司有〔官网上的具体业务〕，想了解你们发版或交付时，需要反复烧录、看日志、测接口的哪些工作最占时间。我们准备以工程师结合 agent 的方式，为一款板建立少量可重复执行的复测流程，交付脚本、结果记录和使用说明。能否与负责固件或项目交付的同事交流 20 分钟，判断是否有适合付费试点的任务？

### 模组 / 开发板厂商

你好，我是 Ben，在做能读取日志、调用调试器并结合真实板卡验证的 Yoma 嵌入式 agent 项目。想了解贵司〔具体型号〕的例程维护或客户技术支持中，哪一种重复任务最耗工程时间。希望与产品或技术支持负责人交流 20 分钟；如果任务匹配，可以围绕一个型号设计一个小范围付费验证。

文案中的具体业务或型号必须来自已读资料并与我们现有证据相符。当前尚无可对外宣称的提效数字。

## 20 分钟交流流程

1. 最近 90 天内最费时间的一次相关任务是什么？让对方描述发生经过。
2. 当时谁处理、用了哪些工具、投入多少主动工程时间？
3. 目前是否还有类似任务、交期与影响是什么？
4. 工程、板卡和允许的运行环境是否可提供？
5. 对方认为怎样的成果值得付费，谁批准，采购流程如何？
6. 约定一个具体下一步，例如提供脱敏任务描述、安排演示或收取报价。

返回格式：线索 ID、对方角色、具体问题、原话、预算/异议、下一步与日期。无回应、拒绝、暂时无任务均如实记录，不填成有意向。
