# 板卡复测启动包

版本：2026-09-09，首次销售实验草稿。平台与排期根据资源盘点和客户任务确认后落定。本文件尚未对外发送。

为已有可运行板卡、需要重复发版或交付的嵌入式团队，把一小段人工复测流程变成可重复运行的验证流程。工作由工程师结合 Yoma 等 agent 工具完成，以晚间异步协作为主要方式。

## 适合的任务

一款板卡、一个已经能正常运行的固件基线、最多三个明确检查点。客户目前需要手动烧录、检查日志或通信结果，并预计后续版本仍需重复这些工作。优先接受已有构建和烧录条件、平台在现有能力覆盖内的项目。

## 试点范围与交付

试点拟报价：人民币 3,000 元。价格是本轮销售测试值。正式报价需明确税费、收款条件、交期及双方验收约定。

首次沟通约 20 分钟，用于判断任务是否匹配。确认匹配和双方条件后，提供以下交付物：

1. **运行基线**：硬件、连接、工具链、固件版本和执行步骤。
2. **最多三个检查点的执行流程**：例如烧录后版本核对、一个外设通信检查、一个既知问题的回归；具体输入、阈值和预期结果由双方约定。
3. **结果与原始证据**：每次运行保存结果、日志和版本，检查失败或环境不可用时明确标出，不把未执行当通过。
4. **可交接资产**：脚本、必要配置、使用说明和一次客户复跑交接；同时保留需要真人操作的步骤。

客户在约定环境独立执行并得到可追查的检查结果，是本次验收的核心。验收同时安排一个已知失败输入或异常条件，确认流程能够报告失败并保留证据。未知故障修复、新硬件设计、多板调度和持续值守另立任务。

初步排期设想：材料齐备、环境可用且完成排期确认后，一周内完成交付，主要在晚间实施。实际接单前核定该安排。内部工作量基线为最多 8 小时主动工程投入；范围若不适合这一基线，应在接单前拆分，实施中范围变化及时告知客户并重新约定。

## 开始前共同确认

- 板卡与固件基线，当前人工复测步骤与未来重复频率。
- 需要的工程、构建步骤、连接说明及板卡接入方式。
- 对代码与数据使用模型 API、远程接入、证据回传的允许范围；本机运行不等同于离线处理。
- 客户技术联系人、可安排的现场操作和验收人。
- 每个检查点的输入、预期、失败条件和证据，以及客户复跑的验收安排。

公开展示案例另征得客户同意；客户项目成果与通用工具的交接范围在任务说明中列明。
