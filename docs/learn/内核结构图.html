Yoma 内核结构图

packages/{agent, ai, coding-agent} 三个包的真实结构。 文件、行数、依赖边全部由脚本解析源码得到,不是手写的 —— 每一条 import 边都对应源码里一条真实的 from "…"。配套讲解见 全景篇 与 索引。

三个包怎么摞起来的

单向分层:ai 是最底下的契约层(不依赖另外两个),agent 在它上面跑循环, coding-agent 在最上面提供工具与宿主适配。箭头上的数字是真实的跨包 import 边数。

文件全景

每一块是一个文件,面积 = 代码行数,颜色 = 所属包,深浅 = 档位(A 主链 / B 外围)。 点任意一块:其它块变暗,只留下它依赖的(虚线框)与依赖它的(点线框),右侧给出详情。
